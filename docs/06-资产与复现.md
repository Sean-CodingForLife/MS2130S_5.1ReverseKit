## 复现命令

以下命令在项目根目录执行。

```powershell
# 7 个镜像全部 lint
Get-ChildItem firmware -Recurse -Filter *.bin | ForEach-Object {
  python tooling\reverse\uac_desc_lint.py $_.FullName
}

# 刷写前先建目录并读回快照（页面“读回快照”，或手工执行）
New-Item -ItemType Directory -Force firmware\snapshots | Out-Null
tooling\flash\ms213x_flash.exe -r firmware\snapshots\<yyyyMMdd_HHmmss>_readback.bin
# 刷写（约 6 分钟，过程中不能拔 USB；页面会强制要求当次有效快照）
tooling\flash\ms213x_flash.exe -w firmware\release\ms2130s_51unlock_20210624.bin

# 录制 5.1（默认写入 captures\recordings）
powershell -File tooling\capture\rec51.ps1 -Seconds 60

# 录完修通道（页面“一键修通道”，或手动 ffmpeg）
ffmpeg -i captures\evidence\ns2_51_unlocked_test.wav -af "pan=5.1|c0=c0|c1=c1|c2=c3|c3=c2|c4=c4|c5=c5" -c:a pcm_s24le captures\fixed\ns2_51_unlocked_test_fixed.wav

# 读 XDATA（先开一个录音让音频流保持打开）
powershell -File tooling\reverse\ms213x_xdata.ps1 -Start 0xF000 -End 0xFFFF -Out registers\batch-2026-11-14\new.bin

# 复算通道落点
python tooling\analysis\wav_scan.py captures\evidence\ns2_51_unlocked_test.wav
```

## 依赖

- Python 3.10+；首次运行 `启动操作台.vbs` 会在 `runtime/venv` 内建环境，不改系统 Python。基础 Python 需要带 pip，依赖由它的 pip `--target` 装进 venv。
- `numpy` 2.5.4、`imageio-ffmpeg` 0.8.1：由 `tooling/ops/requirements.txt` 安装到 `runtime/venv`；`server.py` 在 PATH 之前先用 `FFMPEG_PATH`、`runtime/bin` 和 venv 内置 ffmpeg。
- 系统 ffmpeg：可用环境变量 `FFMPEG_PATH` 显式覆盖；否则依次找 `runtime/bin/ffmpeg.exe`、venv 内置 ffmpeg、PATH。
- PowerShell 5.1 或 7（`tooling/reverse` 的 ps1 用 `Add-Type` 内联 C#，不需要额外模块）
- Linux 救砖需要 Ubuntu 启动盘；Windows 侧刷写走 hidapi，不需要另装驱动，设备管理器里能看到 HID 接口即可。

## 未复算 / 未解

- 第 9 节静态扫描的 309 个写入点、200 个不同地址：需要 8051 反汇编器。
- 刷写耗时对比（Windows 6 分钟 / Linux 1 分钟）：未复测。
- OBS 4K120 + 6ch PCM 链路：需要卡、OBS、4K 源。
- 头部 `0x24DC` 校验算法：未复现。
- AC 终端掩码改 `0x3F` 的副作用：未复测。
- 长时间录制压测：最长实测 130 秒，未做数小时压测。
