## 维护约定

- 项目名只用 `MS2130S_5.1ReverseKit`；`MS2130S` 是芯片型号。
- 改任何固定参数（SHA、长度、码率等），同步更新 [核对记录](核对记录.md) 的复算表。
- 移动任何文件，同步更新 [06-资产与复现](06-资产与复现.md) 与 [项目全景.html](项目全景.html) 的资产页。
- 原始简报只归档、不改写；新结论写进主题文档，并在文首标注对应的原文节号。
